# 观测委托 App 使用说明（v4.0）

面向 **N.A.V.I. Terminal** 内的「观测委托」：色气拓展玩法工具，**不是**琉夏岛正史剧情系统。  
依赖 **yuzuki-phone** 的线上 API / 世界书 / 存储桥接。

---

## 1. 它是什么

在终端里维护一块 **委托板**：

1. 按模式与难度 **生成** 若干条色气委托  
2. **保存** 在本地（关面板、刷新后仍在）  
3. 用多种模板 **导出** 到酒馆输入框，驱动 RP  

适合：想要「本轮玩点什么」时快速抽卡，而不是每次从零写指令。

---

## 2. 界面结构

```
首页（委托板）
├─ 继续上次配置
├─ 观测 / 把玩（进入生成页）
├─ 进行中（当前接取的 1 条）
└─ 委托列表 + 筛选

生成页
├─ 四个可选约束（动作 / 物品 / 协助 / 目标）
├─ 生成条数：1 / 3 / 6
└─ 难度按钮 → 生成并追加到委托板

详情页
├─ 全文 + 生效选项标签
├─ 接取 / 收藏 / 已用 / 未用
├─ 单条重 roll
└─ 导出 / 删除

导出页
├─ 系统下发 / 接单行动 / 仅指标 / 完整卡片
└─ 复制剪贴板
```

---

## 3. 两种模式与镜头

| 模式 | 导出时注入的镜头指令 | 档位 |
|------|----------------------|------|
| **观测** | 【视觉镜头】（给正文模型读） | 静观 / 诱导 / 精测 |
| **把玩** | 【触觉镜头】（给正文模型读） | 轻度 / 沉浸 / 深度 |

镜头指令**不写在生成委托的提示词里**，只在**导出到酒馆输入框**时自动加在正文前（只强调切入/不切入某镜头，不枚举描写要素，以免干扰正文文风）。

指标结构：`事前准备`（可选，社交到场）+ `步骤`（必须条条扣主焦点）。禁止把无关剧情写进步骤。

### 观测三档

| 档 | 含义 |
|----|------|
| **静观** | 自然观察：不指示、不命令、不触碰 |
| **诱导** | 可指示动作 + 可触碰以制造可见状态；**禁止性行为相关指令** |
| **精测** | **性主题**观测（性行为/非插入/SM 等均可）；可任意接触；高潮≠完成任务；全程仍视觉镜头 |

静观时 UI **灰掉「动作指示」**（并强制关闭）。

### 把玩三档

| 档 | 含义 |
|----|------|
| **轻度把玩** | 浅层触摸，无插入无强制高潮 |
| **沉浸把玩** | 敏感区、X交、放尿等 |
| **深度交互** | 插入、玩具、SM、高潮控制 |

### 部位焦点池（观测+把玩共用）

可选（多选最多 5）：胸部、乳头、小穴大阴唇/小阴唇、阴蒂、阴道外侧、阴道里侧、尿道口、足部、臀部。

- **条数**仍由 1/3/6 决定  
- 多选 = 本批焦点池，轮转分到每条  
- **全不选** = 从全部部位随机  
- 不做「选几个生成几条」

### 指标文风

任务委托单：**只要步骤（+注意）**，不写「要看/要感受/记录点」。  
怎么看、摸起来怎样，交给正文文风与肉体描写规则。  
升级后若曾保存过提示词请 **恢复默认**。

## 4. 生成前选项（可关）

打开开关后可填文本；**留空** 表示「开启该维度，但内容交给 AI」：

| 选项 | 作用 |
|------|------|
| 🏃 动作指示 | 固定或随机姿态/动作 |
| 🧴 辅助物品 | 固定或随机道具，并要求实际参与 |
| 👥 协助人员 | 他人协助；填「目标自己」会走主动展示逻辑 |
| 🎯 对象指定 | 固定角色名；开启且留空 = 统一随机目标 |

生成成功后，卡片上会显示 **生效选项标签**（如 `🎯美咲` `🧴丝带`），方便回忆当时约束。

---

## 5. 条数与追加规则

- 可选 **1 / 3 / 6** 条（默认 **3**）  
- **追加** 到委托板，**不会** 覆盖旧委托  
- 板子上限 **40** 条，超出丢弃最旧  
- 解析条数不足时仍会入库，并标记 **不完整**  

观测模式下部位配比随条数变化（不再写死 6=2+2+2）：

- 1 条：部位自选  
- 3 条：建议 胸 / 穴 / 综合 各一  
- 6 条：前 2 胸、中 2 穴、后 2 综合  

---

## 6. 委托状态

| 状态 | 含义 |
|------|------|
| **未用** | 刚生成或重置 |
| **进行中** | 当前接取；全板 **最多 1 条**（新接取会顶掉旧的进行中→未用） |
| **收藏** | 想留着反复用 |
| **已用** | 本轮 RP 已消耗，列表里会淡显示 |

首页可按状态筛选；支持 **清空未用**（不动收藏/进行中/已用）。  
设置里可 **清空全部**。

---

## 7. 导出模板（写入酒馆输入框）

在卡片「导出」或详情「导出」中选择：

| 模板 | 用途 |
|------|------|
| **系统下发** | N.A.V.I. 订单口吻，适合「系统弹了一单」 |
| **接单行动** | 以你接取并执行的简述推动剧情 |
| **仅指标** | 精简焦点，给模型当本轮描写重点 |
| **完整卡片** | 目标+指标+时限+报酬全文 |
| **复制剪贴板** | 不碰输入框，自行粘贴 |

默认勾选：**导出后标记为进行中**（可取消）。

---

## 8. 单条重 roll

详情页 **🎲 重 roll**：

- 沿用该条的 **模式 / 难度 / 选项快照**  
- 只重新生成 **1** 条并 **替换** 原文案  
- **保留** id 与当前状态（如仍是收藏/进行中）  

适合：整批里只有一条不满意。

---

## 9. 继续上次配置

首页 **⚡ 继续上次配置**：

- 恢复上次的模式、选项开关与文本、条数  
- 进入生成页，一键再开一局  

---

## 10. 设置页

- **桥接状态**：是否连上 yuzuki-phone  
- **提示词**：观测 / 把玩 分别保存或恢复默认  
- **设定补全**：世界观补充，每次生成注入  
- **世界书**：开关 + 勾选要注入的书  
- **委托板**：查看容量、一键清空  

---

## 11. 推荐使用流程

1. 确认手机扩展已开、线上 API 可用（首页/设置看桥接状态）  
2. 选 **观测** 或 **把玩** → 按需开选项 → 选条数 → 点难度  
3. 回到委托板，点开喜欢的一条  
4. **导出** 选模板写入输入框 → 正常在酒馆发送推进 RP  
5. 用完点 **已用**；想留着点 **收藏**；下一条可 **接取** 或再生成  

省钱小技巧：先 **1 条** 试水，满意再 **3/6**；或 3 条里对单条 **重 roll**。

## 12. 数据存在哪

经 Terminal `bridge` 双写（优先手机 storage，并 mirror 到 localStorage）：

| Key | 内容 |
|-----|------|
| `navi_term_board_v1` | 委托板 |
| `navi_term_last_cfg` | 上次生成配置 |
| `navi_term_gen_count` | 默认条数 |
| `navi_opt_*` | 选项开关与文本 |
| `navi_supplement` | 设定补全 |
| `navi_term_prompt_store` | 自持提示词 |

换浏览器/清站点数据会丢本地板；与角色卡聊天记录无自动绑定。

## 13. 常见问题

**生成失败？**  
看桥接状态、手机线上 API、控制台 `[NAVI][generate]` 日志。

**条数不够 / 标记不完整？**  
模型格式漂移时仍会尽量入库；可重 roll 或调短提示词后再试。

**和世界书「专属观测委托」不一致？**  
世界书旧条为废案；**以本 App 为准**，属玩法拓展，非正史强制。

**会不会污染酒馆主线？**  
默认只写 **输入框**，由你决定是否发送；不自动改楼层。
